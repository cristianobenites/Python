# 📚 Repositório Python: Desafios e Projetos

Este repositório reúne uma coletânea de **desafios práticos** e **projetos completos em Python**, organizados com fins educacionais, didáticos e de demonstração técnica. Os conteúdos visam apoiar o desenvolvimento de habilidades em programação, automação, análise de dados, desenvolvimento de APIs e integração com serviços externos.

---

## 📁 Estrutura do Repositório

### 🔸 `DESAFIOS/`
Conjunto de exercícios e problemas voltados ao desenvolvimento da lógica de programação com Python, organizados em duas pastas principais:
- `desafio_bots/`
- `desafio_python/`

Estes desafios são apropriados para fixação de conceitos fundamentais, preparação para entrevistas técnicas ou reforço de habilidades específicas com a linguagem.

## 🧪 Tecnologias Utilizadas

- **Python 3.x**
- Bibliotecas populares: `requests`, `tkinter`, `flask`, `pillow`, `asyncio`, `bs4`, `lxml`, `selenium`, entre outras.
- Integração com APIs (GitHub, HuggingFace, TMDB, PSNAWP, PlantUML, Wikipedia etc.)

- Automação de tarefas e análise de desempenho
